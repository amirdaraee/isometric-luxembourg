# Research collection

Reference material for Isometric Luxembourg, gathered for later use (landmark info panels,
3D/interior views, event layers, a historical "fortress era" mode, easter eggs).

| # | Folder | Topic | Status |
|---|---|---|---|
| 1 | `01-landmarks/` | Pictures of the landmarks | done (47 landmarks, 143 images) |
| 2 | `02-buildings-interiors/` | Famous buildings: exteriors, interiors, floor plans | done (22 buildings, 71 interior photos, 1 free plan) |
| 3 | `03-underground-tunnels/` | Maps of the casemates and tunnels under the city | done (22 maps/plans, 20 photos, 3 GeoJSON layers) |
| 4 | `04-city-evolution/` | How the city evolved: walls, castle, fortress, dismantling | done (7 eras, 101 images, 4 GIS files) |
| 5 | `05-events/` | Big recurring and one-off events, for map event layers | done (23 events, 51 images, events.json) |
| 6 | `06-city-details/` | Quarters, important buildings, facts | done (24 quarters, 80 buildings, 397 monument rows, 40 easter eggs, 14 images) |

Conventions used in every folder:
- `README.md`: the findings, written for reuse.
- `sources.json`: every downloaded file with its source page, author, licence and what it shows.
- `images/`: downloaded files, named `<slug>__<what>.jpg`. Only freely licensed files are downloaded
  (Wikimedia Commons, public domain, CC); anything else is listed as a link only.
